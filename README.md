# KRONK

Персональный Telegram-ассистент на TypeScript: математика, календарь, задачи, разбор документов, управляемые автоответы и готовые шутки.

Основной режим использует Bot API и «Автоматизацию чатов» Telegram. Секреты, переписка, базы данных и локальные расширения не входят в репозиторий. Все аккаунты и интеграции настраиваются пользователем самостоятельно.

## Возможности

- Математика: арифметика, проценты и линейные уравнения. Например, `125 × 48` и `x+10=2x`. Периодические дроби округляются до сотых, конечные — максимум до пяти знаков.
- Google Calendar: исходящее «занесу в календарь» с Reply или контекстом запускает создание события. Подтверждение приходит владельцу после успешной записи.
- Задачи: создание из переписки, необязательные дедлайны, открытие, завершение, архив, поиск и напоминания.
- Документы: PDF/DOCX/TXT, выжимки с источниками и комментарии по дополнительному запросу. Разбор отправляется только владельцу.
- Рабочие автоответы: только одобренные ответы из собственной базы знаний, предпросмотр, лимиты и пауза при вмешательстве владельца. Выключены по умолчанию.
- Шутки: «внимание, шутка», «сейчас будет шутка» или `/joke`. Готовая подборка без генерации и расхода API-токенов.
- Первоначальный режим MTProto: демонстрация, общая очередь и ограниченные подтверждаемые регистрации простых бесплатных HTML-форм.

Команда владельца разрешает действие, а сообщение собеседника даёт только контекст. Обычное согласие не создаёт событие или задачу. Ошибка внешнего сервиса не выдаётся за успех.

## Быстрый старт

Нужны Node.js 24 и npm. Для браузерных форм дополнительно нужен Chromium из Playwright.

```sh
npm ci
cp .env.example .env
npm run build
npm run verify
```

В PowerShell файл настроек можно скопировать командой `Copy-Item .env.example .env`. Пример конфигурации использует безопасный демонстрационный режим; модули отправки через Bot API выключены.

Для «Автоматизации чатов» настроить в `.env`:

- `TELEGRAM_BOT_TOKEN` — собственный токен бота.
- `OWNER_TELEGRAM_ID` — собственный ID владельца.
- `BUSINESS_ENCRYPTION_KEY` — 32 случайных байта в base64.
- Нужные флаги `BUSINESS_*_ENABLED`.

Создать ключ: `node -e "console.log(require('node:crypto').randomBytes(32).toString('base64'))"`.

Для реальной работы установить `BUSINESS_DRY_RUN=false`, подключить бота в настройках «Автоматизации чатов» Telegram и запустить:

```sh
npm run business -- --live
```

В Windows фоновый запуск: `./scripts/start-business.ps1`; остановка: `./scripts/stop-business.ps1`. Проверка состояния: `http://127.0.0.1:3001/health`. При выключенном компьютере локальный процесс не работает. Один токен обслуживает один запущенный обработчик.

Для календаря и анализа настроить собственные ключи OpenAI, модель, цены для расчёта бюджета и Google OAuth. [Подключение календаря](docs/calendar-setup.md). Математика и шутки не требуют OpenAI или Google.

## Команды владельца

| Задача             | Команды                                                                          |
| ------------------ | -------------------------------------------------------------------------------- |
| Состояние и пауза  | `/status`, `/pause`, `/resume`, `/help`                                          |
| Задачи             | `/tasks`, `/add текст`, `/today`, `/overdue`, `/done`, `/archive`, `/find текст` |
| Карточка и срок    | `/task номер`, `/due номер новый срок`                                           |
| Документы          | `/docs`, `/doc номер`, `/analyze` через Reply, `/forget_doc номер`               |
| Календарь          | `/calendar`                                                                      |
| Рабочие автоответы | `/replies`, `/reply номер`, `/reply_pause`                                       |
| Шутка              | `/joke`                                                                          |

У задач есть кнопки выполнения, повторного открытия, архива, восстановления и редактирования. Архив скрывает задачу из рабочих списков. Подробнее: [документы](docs/business-documents.md), [автоответы](docs/business-replies.md), [шутки](docs/jokes.md).

## Устройство проекта

`src/services` — получение событий и общие сервисы; `src/tasks`, `src/documents`, `src/replies`, `src/jokes` — функциональные модули; `src/adapters` — внешние API; `src/security` — шифрование и проверка URL; `src/storage` и `migrations` — SQLite и миграции. Интерфейс дополнительных модулей: [расширения](docs/extensions.md).

`npm start` запускает автономную демонстрацию первоначального режима на фикстурах. `npm run serve` запускает его сервис; он использует отдельные настройки `MODE`, `DRY_RUN` и `DATABASE_PATH`. Не запускать оба Telegram-транспорта на одном токене. Для форм: `npx playwright install chromium`. Docker/Compose предназначены для первоначального сервиса; для Bot API заменить команду контейнера на `node dist/business-main.js --live` и настроить отдельную проверку состояния.

## Данные и безопасность

Настоящие конфигурации и содержимое `data/` не публикуются. Ключи и токены не должны попадать в исходники, тесты, журналы, скриншоты или коммиты. Данные хранятся зашифрованно; ключ шифрования хранится отдельно от базы. Для утраченного ключа автоматического восстановления нет.

Внешние сообщения и документы считаются данными, а не инструкциями. Действуют ограничения размера, времени, контекста, расходов и хранения. Неоднозначная отправка сообщения не повторяется автоматически. Подробности: [модель угроз](docs/threat-model.md), [модель данных](docs/data-model.md), [проверки](docs/verification.md).

Перед коммитом: `npm run check:public` и просмотр `git diff --cached`. Проверка не заменяет внимательный просмотр содержимого и метаданных коммита.
