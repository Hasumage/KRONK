# ADR 0002: Bot API для математического сценария

Статус: принято.

Для математических ответов в личных чатах используется подключение бота через «Автоматизацию чатов». Оно отделено от первоначального MTProto-транспорта. См. [официальный анонс](https://telegram.org/blog/ai-bot-revolution-11-new-features#chat-automation-in-profiles) и [документацию](https://core.telegram.org/api/business).

Добавлен отдельный процесс `business-main`, который подписывается на `business_connection`, `business_message` и команды владельца. Ответ отправляется методом `sendMessage` с исходными `business_connection_id`, `chat_id` и Reply-ссылкой на пример. Перед ответом проверяются текущие права соединения и owner ID; неизвестные события подключения восстанавливаются через `getBusinessConnection`. API key OpenAI, MTProto-сессия и Google OAuth не нужны.

Арифметика вычисляется ограниченным рекурсивным парсером на BigInt-дробях, без eval и вызовов модели. Степени, глубина, токены и размер чисел ограничены. Нематематические сообщения игнорируются. Права на профили, подарки, звёзды и удаление сообщений не используются.

Настройки и БД отделены от общего MVP: `BUSINESS_*`, `data/business.sqlite`. Сохраняются минимальные ID дедупликации и зашифрованный ответ. После неоднозначного сетевого сбоя `sending` превращается в `uncertain`, повторной отправки нет. Пользовательские `/pause` и `/resume` сохраняются между запусками.

Математический модуль отправляет только результат вычисления. Рабочие автоответы из базы знаний используют отдельные настройки и явную маркировку.
