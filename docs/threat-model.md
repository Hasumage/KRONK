# Модель угроз

Активы: Telegram session, OAuth refresh token, профиль, переписка и документы, право писать от аккаунта. Доверены владелец, локальные конфигурация/ключ и проверенная база знаний. Модель, чужая переписка, документы и сайты не являются источниками полномочий.

| Угроза                   | Защита                                                                                                        | Остаточное ограничение                                                                 |
| ------------------------ | ------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| Prompt injection         | Отдельные system/user, строгая схема, проверка источников/evidence, policy, allowlist инструментов            | Семантическое решение модели не доказательство; live требует оценки на реальных фразах |
| Доступ к служебному боту | Проверка числового owner ID и private chat для сообщений и callback                                           | Компрометация аккаунта владельца вне границ MVP                                        |
| Кража БД                 | AES-GCM для содержимого и токенов, ключ отдельно                                                              | ID, времена и статусы открыты; процесс с env может расшифровать                        |
| Утечка в логи            | Только фиксированные коды ошибок, без ответов провайдеров и raw update                                        | `inspect` намеренно расшифровывает уведомления локальному оператору                    |
| Дубли / падение          | Уникальные ключи, Calendar ID, outbox uncertain, одноразовая регистрация                                      | Возможен пропуск уведомления; exactly-once Bot API не заявляется                       |
| SSRF / rebinding         | HTTPS allowlist, все DNS IP public, CONNECT с фиксированным IP, запрет redirects и JS                         | Сопровождение браузера и контейнерная изоляция обязательны                             |
| Утечка профиля           | Профиль не подставляется в DOM до подтверждения, хеш структуры формы                                          | После подтверждения владелец доверяет разрешённому домену                              |
| Вредоносный файл         | Только PDF/DOCX/TXT, сигнатуры, размер/символы/PDF-страницы, отдельный процесс, тайм-аут, без макросов        | Нативная память ограничивается контейнером; OCR не реализован                          |
| Спам / вмешательство     | Auto-reply off, рабочая тема+чат, ночное окно, owner pause, cooldown, суточный лимит, только готовый KB-текст | Ошибка тематической классификации требует проверки fixtures и live eval                |
| Перерасход API           | Суточный лимит, ограничение контекста/ответа, атомарный резерв USD до вызова                                  | Цены задаёт оператор; резерв намеренно выше фактических расходов                       |

Не обходятся FloodWait, CAPTCHA, платёжные формы и требования входа. Проект не подключает реальный аккаунт при установке или `npm start` с настройками по умолчанию.
