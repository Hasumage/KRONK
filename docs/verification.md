# Проверки

`npm run verify` проверяет TypeScript исходников и тестов, затем запускает Vitest. Тесты используют синтетические аккаунты и данные, изолированные SQLite-базы и подменённые внешние API. Проверяются права владельца, явное намерение, шифрование, дедупликация, лимиты, очередь, паузы, восстановление и неоднозначные сетевые исходы.

`npm run check:public` проверяет подготовленные к коммиту имена файлов и известные форматы секретов. После этого необходимо просмотреть `git diff --cached` и проверить автора коммита. Не публиковать `.env`, рабочие базы, сессии, OAuth-файлы, переписку, скриншоты кабинетов и локальные расширения.

Для проверки внешних интеграций пользователь подключает собственные аккаунты в отдельном тестовом окружении. Утилиты `scripts/check-*.mjs` могут обращаться к API и расходовать средства; их назначение указано в начале каждого файла. Локальные результаты такой проверки и личные данные не входят в отчёты репозитория.

Успешные автономные тесты не гарантируют доступность внешних сервисов, актуальность прав аккаунта и качество распознавания на произвольном пользовательском материале.
